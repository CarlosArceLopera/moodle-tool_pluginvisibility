# moodle-tool_pluginvisibility

Moodle admin tool plugin for managing plugin visibility.

## Installation

1. Copy the plugin directory to `{moodle_root}/admin/tool/pluginvisibility`
2. Visit Site administration to complete the installation
3. Access the plugin via Site administration > Server > Plugin visibility

## Requirements

- Moodle 5.1 or later

## Files Structure

The plugin includes the following default Moodle files:

- `version.php` - Plugin version and metadata
- `settings.php` - Plugin settings and admin menu registration
- `index.php` - Main plugin page
- `lang/en/tool_pluginvisibility.php` - English language strings
- `db/access.php` - Capability definitions
